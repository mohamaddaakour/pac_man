# Pac-Man: Ghosts! More ghosts!

A complete Pac-Man game written in Python 3.10+ with a clean, modular architecture. Each level is a maze generated by an assigned external A-Maze-ing package (with `PERFECT=False`). Four ghosts chase you with BFS pathfinding, and they flee when you eat a super-pacgum.

## Features

- 10 or more levels with a timer, and your score and lives carry over between them
- Config file in JSON with `#` and `//` comments, safe defaults, and clear messages for bad values
- Persistent top-10 highscores with name validation
- Cheat mode (invisibility) for evaluation
- Main menu, HUD, pause, game over and victory screens
- Game core separate from the graphics, so it can be tested and played in a terminal

## Run

```bash
python3 pac-man.py config.json
```
